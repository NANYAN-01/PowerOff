# PowerOff - 定时关机工具

一个基于PyQt5开发的Windows定时关机工具，支持设置定时关机、重启和注销操作。

![应用图标](app_icon.ico)

## 功能特点

- 🕐 **多种计时方式**：支持指定日期时间和倒计时两种方式
- 💻 **多种操作类型**：支持关机、重启、注销三种操作
- 📌 **窗口置顶**：可将窗口设置为始终显示在最前端
- 🎨 **美观界面**：现代化UI设计，操作简单直观
- 🚀 **一键操作**：支持立即执行操作
- ❌ **计划取消**：可随时取消已计划的关机任务

## 系统要求

- Windows 7/8/10/11
- 不需要安装Python环境（使用已打包的可执行文件）

## 安装与运行

### 方式一：使用可执行文件（推荐）

1. 从`dist`文件夹中获取`PowerOff.exe`
2. 双击运行即可使用

### 方式二：从源码运行

1. 确保已安装Python 3.x
2. 安装依赖库：
   ```
   pip install PyQt5
   ```
3. 运行主程序：
   ```
   python main.py
   ```

## 使用说明

### 设置关机时间

#### 方式一：指定时间
1. 选择"指定时间"选项
2. 设置关机日期和时间
3. 点击"确定"按钮设置任务

#### 方式二：倒计时
1. 选择"递减方式"选项
2. 设置小时、分钟和秒数
3. 点击"确定"按钮设置任务

### 设置关机选项

- **关机**：执行系统关机操作
- **注销**：注销当前用户
- **重启**：重启系统
- **强制**：强制执行操作（推荐勾选）

### 其他功能

- **置顶**：勾选后窗口将始终显示在最前端
- **取消计划**：取消所有已设置的关机计划
- **立即关机**：立即执行选定的操作

## 打包说明

本项目使用PyInstaller打包为独立可执行文件：

```bash
pyinstaller --onefile --icon=app_icon.ico --name="PowerOff" --windowed main.py
```

打包后的可执行文件位于`dist`文件夹中。

## 注意事项

1. 程序需要管理员权限才能执行关机、重启操作
2. 设置的关机时间必须晚于当前时间
3. 倒计时必须大于0秒
4. 程序使用Windows的`shutdown`命令实现关机功能
