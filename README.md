# PowerOff - Windows 定时电源工具

一个基于 PyQt5 的 Windows 定时电源工具，支持关机、重启、注销、睡眠、休眠、锁定六种操作，
提供倒计时状态条、系统托盘常驻与计划持久化。

![应用图标](app_icon.ico)

## 功能特点

- 🔌 **六种电源动作**：关机 / 重启 / 注销 / 睡眠 / 休眠 / 锁定
- 🕐 **两种计时方式**：指定日期时间、倒计时（含 5/10/30/60 分钟快捷预设）
- 🔁 **闹钟式重复计划**：不重复 / 每天 / 工作日 / 自定义周几 / 指定日 / **法定工作日**
  （按中国调休规则自动跳过周末与法定假日、调休补班日照常执行，数据随国务院通知每年更新）
- 📋 **计划列表**：主界面「已设定计划」表格展示规则、动作、下次执行时间，支持启用/停用与单个删除
- 💾 **关机前自动保存**：对文档类窗口（Office / WPS / 记事本 / VS Code 等白名单）逐个激活并发送
  Ctrl+S，尽力避免文件丢失（默认开启，可一键关闭）
- 🔔 **右下角 Toast 通知**：计划添加/删除、临期 60 秒、关机前保存中，均有 Windows 原生弹窗通知
- 🧠 **混合执行后端**：
  - 强制关机/重启 → 系统级 `shutdown /t`，**关闭本程序后仍然生效**
  - 温和关机与注销/睡眠/休眠/锁定 → 本程序倒计时执行（需保持运行，可收进托盘）
  - 重复计划 → 本程序调度执行（需保持运行）
- 📊 **状态条倒计时 + 颜色分级**：绿 >30min、黄 30–10min、橙 10–1min、红 <1min 闪烁
- 📌 **系统托盘常驻**：右键菜单（显示窗口/取消计划/退出），关窗自动收进托盘
- 💾 **计划持久化**：单次与重复计划写入 `%APPDATA%\PowerOff\state.json`，程序重启自动恢复
- 🚪 **单实例**：二次启动自动唤起已运行窗口
- ⚙️ **偏好记忆**：计时方式、重复规则、动作、强制、置顶、自动保存等偏好自动保存
- 🚀 **开机自启**：写入 `HKCU\...\Run` 注册表

## 系统要求

- Windows 7 / 8 / 10 / 11
- 使用 exe 无需安装 Python；源码运行需 Python 3.8+

## 安装与运行

### 方式一：使用可执行文件（推荐）

从 `dist/PowerOff.exe` 或 GitHub Releases 获取，双击运行。

### 方式二：从源码运行

```bash

```

## 使用说明

1. **计时方式**：选择「指定时间」设置日期与时刻，或选择「递减方式」填入时分秒（也可点快捷预设）
2. **重复**：选择规则后点「确定」即加入计划列表
   - 不重复：与指定时间一致，关机/重启可走系统级计划（关掉程序仍生效）
   - 每天 / 工作日 / 自定义（勾选星期）/ 指定日（可添加多个日期）/ 法定工作日：由本程序调度执行
3. **关机选项**：勾选动作；「强制」仅对关机/重启有效（强制关闭未响应的应用）
4. **已设定计划**：表格中可停用/启用、单个删除；「取消计划」取消单次倒计时与系统级计划
5. **关机前自动保存**：左上角勾选框，默认开启；关机/重启/注销前对文档窗口逐个 Ctrl+S
6. **立即执行**：二次确认后立即执行当前动作
7. **置顶 / 开机自启**：左上角勾选框

## 注意事项

1. **无需管理员权限**：普通账户默认拥有 `SeShutdownPrivilege`；若公司策略限制，命令会失败并如实提示
2. **温和关机与本地倒计时**（注销/睡眠/休眠/锁定）依赖本程序存活，退出程序前会提示；强制关机/重启走系统计划，不受影响
3. **无法查询其他程序设定的关机计划**（Windows 未提供查询 API），但「取消计划」会尝试取消系统级计划并按返回码反馈
4. **睡眠**：若系统启用了休眠（`HibernateEnabled=1`），睡眠可能实际进入休眠，程序会弹窗确认
5. 设置的指定时间必须晚于当前时间
6. **法定工作日**依赖 `chinesecalendar` 数据（每年 11 月随国务院通知更新）；当年数据未发布时退回「周一~周五」判断
7. **自动保存为尽力而为**：只对白名单文档应用生效，无法处理未响应或全屏独占的程序
8. **重复计划由本程序执行**：程序未运行期间错过的触发不会补执行（5 分钟内的短暂卡顿会补执行），恢复后自动排到下一次

## 已修复的历史缺陷（v1.0 → v2.0）

- 注销（`/l`）与 `-t/-f` 组合会被 Windows 忽略，导致「6 小时后注销」变成**立即注销**
- `os.system` 不检查返回码，命令失败仍提示「计划任务已设定」
- 「开机自启」勾选框未接任何逻辑
- 仓库中泄露的 API key 测试文件已删除（请自行轮换该 key）
